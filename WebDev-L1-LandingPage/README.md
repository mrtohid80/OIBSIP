# Task 1: Landing Page

## Project Overview
A responsive and modern product landing page for a fictional SaaS product ("CloudFlow"). Built entirely with HTML5 and CSS3 as part of Level 1 for the Oasis Infobyte Internship Program (OIBSIP).

## Features
- Sticky navigation bar with internal jump links.
- Hero section with bold heading, descriptive subtitle, and Call-to-Action (CTA) buttons.
- Distinct Features section using responsive CSS Grid cards.
- Informational About section highlighting key performance stats.
- Structured footer with navigation links, branding, and contact channels.
- Fully responsive design using media queries, CSS Flexbox, and CSS Grid.

## Tech Stack
- HTML5
- CSS3
