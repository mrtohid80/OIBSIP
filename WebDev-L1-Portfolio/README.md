# Task 2: Personal Portfolio Website

## Project Overview
A clean, minimal, and fully responsive developer portfolio built with HTML5 and CSS3. Created as part of the Oasis Infobyte Internship Program (OIBSIP) Web Development Level 1 track.

## Features
- Hero section with personal avatar initials, title, and CTA action buttons.
- About Me summary describing current education and technical interests.
- Visual skills grid showcasing frontend competencies.
- Projects section highlighting completed internship tasks with repository links.
- Interactive contact links and smooth-scroll navigation across sections.

## Tech Stack
- HTML5
- CSS3 (Flexbox & CSS Grid)
