# Task 3: Temperature Converter Website

## Project Overview
An interactive browser-based temperature converter tool developed using HTML5, CSS3, and Vanilla JavaScript for Level 1 of the Oasis Infobyte Internship Program (OIBSIP).

## Features
- Real-time conversion across Celsius, Fahrenheit, and Kelvin.
- Comprehensive input validation rejecting non-numeric values.
- Edge-case handling preventing absolute zero violations (< -273.15°C, < -459.67°F, < 0 K).
- Clean, dark-mode centered user interface.

## Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla ES6)
